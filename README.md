# AI Translator

The purpose of this project is to create a translator for written language.

Byte Pair Encoding is used as the tokenizer and the Transformer Architecture used as predictive model.

Both the model and tokenizer, with large vocabulary (> 20k), need to be trained on large datasets (> 1 GB).
